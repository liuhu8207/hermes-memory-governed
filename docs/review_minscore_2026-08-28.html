修复（本轮已落地并实测）_search_l3 返回前做 max 归一化
_recall.py :: _search_l3（results 返回前）
# Normalize scores to 0~1 (max -> 1.0) so L3 scores are
# comparable with L2 scores and survive MIN_SCORE filtering.
if results:
    max_score = max(r.score for r in results)
    if max_score > 0:
        for r in results:
            r.score = r.score / max_score
归一化保留 FTS5 排序与时间衰减的相对差异（新消息 1.0 > 旧消息 0.899），同时把 L3 映射到与 L2 可比的 0~1 区间——统一阈值从此安全，且 L2/L3 混排不再失真（顺带闭环了遗留的量纲问题）。
