二、health 脚本 warning/errors 分离（遗留项闭环）

改动内容
HealthCheck新增 errors 列表；check() 失败进 errors（不再混入 warnings）
summary()JSON 报告新增 errors 计数字段
main() 退出码return 1 if h.warnings else 0 → return 1 if h.errors else 0——warning（如 lancedb 未装、无候选文件）不再导致 daily pipeline 误报 FAIL
