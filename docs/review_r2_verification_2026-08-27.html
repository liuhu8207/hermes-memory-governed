三、仍存在的问题

严重FTS5 中文修复无效，且英文检索被搞坏
_recall.py :: _build_fts_query（逐字符 prefix：'"c"* OR "o"* OR ...'）
中文依旧查不到：FTS5 默认分词器把中文整句当单个 token，「记得」→ "记"* OR "得"* 只匹配以「记/得」开头的 token，句子「我记得用户喜欢喝咖啡」不以「记」开头 → 0 hits。逐字符 prefix 只能命中「查询词恰好是句子开头」的情况。

英文灾难性误报：查询 "coffee" 展开为 "c"* OR "o"* OR "f"* OR "f"* OR "e"* OR "e"*，任何以 c/o/f/e 开头的 token 都命中——"cat"、"orange" 全被召回。实测 6 条库中 "coffee" 命中 3 条（2 条无关），"python" 命中 4 条（3 条无关）。原本精确的英文检索被这个改动破坏了。
实测： query='记得' -> 0 hits query='咖啡' -> 0 hits query='coffee' -> 3 hits: ['The cat sat on the', 'I drank coffee yes', 'Orange juice is he'] query='cat' -> 3 hits: ['The cat sat on the', 'Python is a progra', 'I drank coffee yes']
严重parallel_recall 超时只修了一半 + 新 bug
_recall.py :: parallel_recall
① TimeoutError 已捕获，不再崩溃 ✅
② 但 with ThreadPoolExecutor(...) 退出时 shutdown(wait=True) 仍阻塞等待慢任务完成——实测配置 0.5s 总耗时 3.00s，超时配置依然无效。
③ 新 bug：超时后 for future, layer in futures.items(): if future.done() 把已完成 future 的结果与 as_completed 已收集的结果重复合并——实测 FAST 结果出现 2 次。
实测：parallel_timeout_seconds=0.5，慢 L2 3s 返回 ['FAST', 'FAST']，耗时 3.00s（重复收集 + 阻塞确认）
严重pyproject 构建仍失败（backend 已修，包发现未配）
pyproject.toml
backend 改为 setuptools.build_meta 正确，但 setuptools flat-layout 检测到 config 和 plugin 两个顶层包目录，拒绝自动发现。需要显式配置： [tool.setuptools.packages.find] include = ["plugin*"] 或 [tool.setuptools] packages = ["plugin", "plugin.memory_governed"]。
实测：pip install . --no-deps --dry-run error: Multiple top-level packages discovered in a flat-layout: ['config', 'plugin'].
高L2 数据一致性：无 embedding 时写入的数据，装 embedding 后不可见
_sync.py :: _index_l2 · _recall.py :: _search_l2_vector
无 sentence-transformers 时写入的事实 vector 列为 NULL；之后安装 embedding 依赖，向量搜索对 NULL vector 行静默返回空——旧数据在语义检索模式下全部消失（文本降级仍可查到，但一旦启用向量模式就看不到）。升级 embedding 时需要给存量数据补向量（迁移脚本）。
实测：写入 1 条（vector=None），伪造 embed_fn 后 search('python') -> 0 条

四、剩余修复建议

优先级事项方案
P0FTS5 查询重构英文：恢复 OR of quoted terms（逐字符 prefix 只用于 CJK 场景也要先确认有效）；中文：jieba 分词（写入+查询两侧）或 FTS5 trigram（SQLite 3.34+，≥3 字符查询），或 LIKE 子串兜底
P0parallel_recall 超时彻底修复不用 with 管理线程池（手动 shutdown(wait=False)），或用 dict 记录已收集 future 避免重复
P0pyproject 包发现配置加 [tool.setuptools.packages.find] include=["plugin*"]，验证 pip install .
P1L2 embedding 迁移提供 re-embed 脚本为存量 NULL vector 行补向量
P2测试补盲区FTS5 中文/英文精确性、超时重复收集、pip 构建验证
